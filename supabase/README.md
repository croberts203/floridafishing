Supabase pieces for fishforecast.net (project rkxzfzzjzrnkiyopbdke):
- functions/noaa-tides: public read-only proxy (adds CORS): NOAA tide stations + high/low predictions,, live readings (?now=) from the nearest NOAA gauge, NDBC buoy and USGS stream gauge, and lake/pond/reservoir/river lookup (?water=) from the USGS National Hydrography Dataset.
- functions/catch-photo: signed-in photo → species + length (needs ANTHROPIC_API_KEY secret; 20/day per user, shared ai_usage table).
- tables forecast_catches / forecast_settings: per-user catch log and settings, row-level security (owner only).

- functions/bite-alerts: push notifications for Fish Bite Forecast. `?vapid` returns the public key; `?test` (signed-in user) sends a test; `?run` (cron, x-cron-key) scores each alert rule with the app's engine (core.js, generated by build.js) and sends at most one bite alert per rule per day plus marine advisories. Scheduled by pg_cron job `forecast-bite-alerts` (10:41, 16:41, 22:41 UTC).
- tables: forecast_alerts (rules), forecast_push_subs (devices), forecast_secrets (VAPID + cron key, service role only).
- storage bucket catch-photos (private): <user id>/<catch id>.jpg and _t.jpg; users can only read and write their own folder.
